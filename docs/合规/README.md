# 合规材料

本目录是 StudyCloud 上架与运营所需的法律文本与披露清单。

> **全部为草案，均未经法务审阅，不得直接用于上架或对外公示。**
> 这些文本依据 M0–M5 的**实际代码实现**编写，描述的是系统真实做了什么。
> 代码改动涉及数据收集、权限、第三方组件时，**必须回来同步修改本目录**。

## 文件

| 文件 | 用途 | 依据 |
|---|---|---|
| [隐私政策](./隐私政策.md) | 对用户公示，App 首启需弹窗同意 | 《个人信息保护法》第 17 条 |
| [儿童个人信息保护规则](./儿童个人信息保护规则.md) | 单独成文，监护人单独同意 | 《儿童个人信息网络保护规定》第 9 条 |
| [权限与第三方 SDK 清单](./权限与第三方SDK清单.md) | 应用商店提审材料、App 内可查 | 工信部《关于开展 App 侵害用户权益专项整治的通知》 |
| [用户服务协议](./用户服务协议.md) | 注册时同意 | 《民法典》合同编 |
| [开源软件声明](./开源软件声明.md) | App 内「关于」页可查 | 各开源许可证的署名要求 |
| [上线合规检查清单](./上线合规检查清单.md) | 发布门禁 | 汇总，含**尚未实现**的法规要求 |

## 运营主体信息（**上线前必须填写**）

以下占位符出现在上述各文本中，发布前须统一替换为真实信息：

| 占位符 | 含义 |
|---|---|
| `<运营主体全称>` | 营业执照上的公司全称 |
| `<统一社会信用代码>` | 营业执照编号 |
| `<注册地址>` | 营业执照地址 |
| `<隐私联系邮箱>` | 个人信息保护专用邮箱，须有人实际查收 |
| `<客服电话>` | 工作时间可接通 |
| `<ICP备案号>` | 管理后台域名的备案号，须在页面底部展示 |
| `<个人信息保护负责人>` | 《个人信息保护法》第 52 条，达到规模须指定 |
| `<运营主体所在地>` | 用户协议的争议管辖地 |
| `<保留期待定，建议 24 个月>` | 学习事件的保留期，须与实际清理任务一致 |

列出四份对外文本中未替换的占位符（`<br>` 是 HTML 标签，不计；
本文件与检查清单因列举占位符本身而排除）：

```bash
grep -n -oE '<[^>]{2,}>'   docs/合规/{隐私政策,儿童个人信息保护规则,用户服务协议,开源软件声明}.md   | grep -v '<br>'
```

## 与工程文档的关系

本目录面向用户与监管；工程侧的数据字段清单、安全措施实现细节在
后端仓库 `studycloud-admin-api` 的 `docs/隐私政策与儿童个人信息保护规则.md`。
两者口径必须一致，**不一致时以代码为准**，然后两边都改。
