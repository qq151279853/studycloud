## 7. 开发期约定

**以下任一项变更时，必须回来更新 `docs/合规/`：**

| 变更 | 需同步的文件 |
|---|---|
| 新增 / 删除 Android 权限 | 权限与第三方 SDK 清单 |
| 新增 / 升级第三方依赖 | 权限与第三方 SDK 清单、开源软件声明 |
| 新增收集的数据字段 | 隐私政策 §2、儿童规则 §3 |
| 新增数据接收方 | 隐私政策 §4 |
| 改变数据保留期 | 隐私政策 §6、儿童规则 §6 |

建议在 CI 中加一道检查：`AndroidManifest.xml` 与 `build.gradle.kts` 变更时，
若 `docs/合规/` 未同时变更则给出警告（**提醒而非阻断**，避免误伤纯重构）。
