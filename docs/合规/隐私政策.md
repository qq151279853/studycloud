## 1. 这份政策说明什么

StudyCloud 由家长在电视或平板上安装，设定「看多久需要答题、答对奖励多少时长」的规则，
孩子答题后获得继续观看的时长。家长在管理后台维护题库、设置规则、查看学习记录。

本政策说明我们**收集什么、为什么收集、存多久、给谁看**，以及您如何行使权利。

**我们的基本原则**：孩子的数据只用于实现您设定的管控规则和向您展示学习情况。
我们不出售、不共享、不用于广告、不用于训练模型。

## 2. 我们收集什么

### 2.1 您（家长）的账号信息

| 信息 | 是否必填 | 为什么需要 |
|---|---|---|
| 用户名 | 必填 | 登录标识 |
| 密码 | 必填 | **我们只存储加盐哈希值，不存明文**，任何界面和接口都不会显示 |
| 邮箱或手机号 | **选填** | 仅用于找回账号。不填不影响使用 |

不填写邮箱或手机号时，账号一旦丢失密码将无法找回，请您自行权衡。

### 2.2 设备信息

| 信息 | 为什么需要 |
|---|---|
| 设备标识 | 区分您名下的多台设备、下发对应规则。**该标识由 App 首次启动时随机生成**，不是 IMEI、不是 ANDROID_ID，卸载重装即变更 |
| 设备名称、型号、系统版本、App 版本 | 您在后台区分自家设备；我们排查兼容性问题 |
| 最后在线时间、最后同步时间 | 您判断设备是否正常工作 |
| 登录 IP 与浏览器标识 | 异常登录排查、远程登出。**仅在登录记录中保留，随登录态过期清理** |

### 2.3 孩子的学习数据

**这是本产品最敏感的部分。** 完整清单如下：

| 我们收集 | 我们不收集 |
|---|---|
| 答题结果（对 / 错）、题目难度 | 孩子的姓名、学校、班级、身份证件 |
| 答题用时、实际观看时长 | 孩子的照片、位置、通讯录 |
| 完成任务组数、加练池状态 | 设备上其他应用的使用明细 |
| 主观题的文字作答与手写图片 | 麦克风、摄像头内容 |

**孩子在系统中没有独立账号**，以「设备」或您自定义的昵称标识。
我们不要求、也无法获知孩子的真实身份。

关于「设备上其他应用的使用明细」：App 会读取系统提供的前台应用信息，
用于判断「现在是不是在看视频」从而决定是否扣减时长。**该信息只在设备内存中使用，
不上传、不存储、不向您展示**。详见[权限与第三方 SDK 清单](./权限与第三方SDK清单.md)第 1.3 节。

### 2.4 主观题手写图片

手写笔迹可能具有可识别性，单独说明：

- 仅在孩子作答主观题时产生，存储于对象存储
- **保留 90 天后自动删除**；批改完成后您可随时手动删除
- **不用于任何模型训练**

## 3. 我们不做的事

- 不向第三方出售或共享孩子的学习数据
- 不使用孩子的数据进行广告定向或用户画像
- 不使用孩子的作答训练人工智能模型
- 不集成任何广告、统计分析、推送、社交登录 SDK（见 SDK 清单）
- 不收集用于跨应用追踪的设备标识（IMEI / OAID / MAC）

## 4. 数据去哪里

### 4.1 默认不出境

服务器部署在中华人民共和国境内。默认情况下，孩子的学习数据只在
您的设备、您的浏览器和我们的服务器之间流动。

### 4.2 唯一的例外：您自行开启的 AI 批改

主观题可以由人工批改（默认），也可以由您配置第三方 AI 服务自动批改。

**开启 AI 批改后，题目、评分标准与孩子的答案（含手写图片）会发送到您自己配置的第三方服务。**

我们在工程上施加的约束：

- 该功能**默认关闭**，必须由您主动开启并填写服务地址与密钥
- 开启前界面会明示上述数据流向，并提示「**若该服务在境外，数据将跨境传输**」
- 服务地址**必须是 HTTPS**，服务端强制校验，HTTP 地址会被拒绝保存
- 您的 API 密钥以 **AES-256-GCM 加密存储**，任何读取接口只返回「是否已配置」，不回显明文
- 我们不代为选择服务商，不从中获取任何数据

**请注意**：第三方服务如何处理这些数据，受该服务自身的隐私政策约束，不在我们的控制范围内。
如该服务位于境外，您作为开启方需自行评估跨境传输的合规风险。**建议优先使用人工批改。**

### 4.3 法律要求的披露

仅在法律法规明确要求、或为保护他人重大合法权益所必需时，我们才会依法定程序提供相关数据，
并在法律允许的范围内告知您。

## 5. 我们如何保护这些数据

| 措施 | 实现 |
|---|---|
| 传输加密 | 全站 HTTPS，非开发环境强制 HSTS 与 HTTPS 重定向 |
| 密码 | PBKDF2-HMAC-SHA512，210,000 次迭代，加盐存储 |
| 登录态 | 登录凭据只存哈希；每次使用即轮换；检测到重放会作废整条凭据链 |
| 设备端存储 | 凭据存于系统加密存储（`EncryptedSharedPreferences`），**不存储您的密码** |
| 越权防护 | 数据库层强制家庭隔离，每类资源均有跨家庭访问的自动化测试 |
| 密钥保护 | AI 服务密钥 AES-256-GCM 加密，主密钥独立保管 |
| 日志 | 禁止记录密码、凭据、API 密钥、手写图片内容 |
| 审计 | 所有写操作记录「谁 / 何时 / 从哪个 IP / 改了什么」 |
| 限流 | 登录、导入、同步分别限流，防撞库与滥用 |

尽管如此，**没有任何措施能保证绝对安全**。发生个人信息泄露时，
我们将按《个人信息保护法》第 57 条的要求及时告知您并向监管部门报告。
