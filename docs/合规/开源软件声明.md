# 开源软件声明

StudyCloud 使用了下列开源软件。我们遵守各自许可证的要求，在此声明并致谢。
各许可证全文可在对应项目主页获取。

本产品自身以 [MIT 许可证](../../LICENSE)发布。

> 本清单依据 `app/build.gradle.kts`、`core-gate/build.gradle.kts`、
> 后端 `Directory.Packages.props` 与前端 `package.json` 核对生成。
> **升级或新增依赖后须同步本文件**——这是许可证的署名义务，不是可选项。
